# Vatsal Garg Portfolio
Static HTML, CSS and JavaScript portfolio based on the supplied Profiler reference.

Run locally: `node server.mjs`, then open http://127.0.0.1:5173.
The preview server binds to loopback and serves only the six explicit public files.

Includes the supplied portrait, six projects (Bando excluded), education, certifications, skills, contact links, a text profile download, navigation dialog, scroll reveals, progress, parallax and counters. Reduced-motion settings are respected.

No external dependencies, form submissions, or tracking. Individual project and certificate URLs were not supplied; no fabricated links are used. The supplied 400px portrait is displayed in color with a right-aligned fade and is naturally softer when enlarged.

Existing site link: https://vatsalgargg.github.io/Portfolio_Self

Responsive layouts cover compact phones, tablets, landscape and wide desktops. Touch controls have 44px targets; phone motion avoids large blur effects and photo parallax. The VG signature redraws on entry. Reduced-motion preferences are respected. Run `node check.mjs` with the preview server running to verify public assets and private-file protection.
