# Vatsal Garg Portfolio

Static HTML, CSS and JavaScript portfolio based on the supplied Profiler reference.

Existing site link: https://vatsalgargg.github.io/Portfolio_Self

Run locally: `node server.mjs`, then open http://127.0.0.1:5173. The preview server binds to loopback and serves only the explicit public files.

Includes the supplied color portrait, six projects (Bando excluded), education, certifications, skills, contact links, a text profile download, navigation dialog, scroll reveals, progress, parallax, counters and animated VG signature.

Responsive layouts cover compact phones, tablets, landscape and wide desktops. Touch controls have 44px targets; phone motion avoids large blur effects and photo parallax. The VG signature redraws on entry. Reduced-motion preferences are respected.

Run `node check.mjs` with the preview server running to verify public assets and private-file protection.

No external dependencies, forms or tracking. Individual project and certificate URLs were not supplied; no fabricated links are used. The supplied 400px portrait is naturally softer when enlarged.
